# A5P2 - Dependency-preserving partial rollback

**Track:** Track 1  
**Application:** Control-plane and data-plane deployments for DER management systems

> This dataset is synthetic, generated by gen_author5.py with seed 2078. It must be described as synthetic in any publication.

## Simulated scenario

A distributed energy resource management system (DERMS) consists of 16 control-plane and data-plane components with a fixed dependency graph (API, message, schema, config edges). Each release changes 2-8 components. Some changes are faulty; symptoms propagate to consumers. Rolling back a provider that changed its contract forces dependent consumers that adopted the new contract to roll back too, and schema migrations couple consumers with their data stores. The task is to pick the minimal rollback set that restores health while preserving dependencies.

## How it was generated

- 1,500 releases; P(faulty) = sigmoid(-3.2 + log LOC + schema + contract - coverage - bake time).
- Symptom strength 2.5 at faulty components, attenuated x0.5 per hop to consumers (2 hops); observed metrics = noisy functions of symptom strength, stronger DER-command/telemetry impact on data-plane components.
- must_rollback = closure of faulty components over contract-change (90%) and schema-coupling rules on the dependency graph.
- Unchanged healthy components logged with 45% probability; edges table lists edges touching changed components.
- Noise: 5% Gaussian on metrics, ~0.7% outliers, 1-3% missing (latency delta, telemetry gap, coverage).

## Suggested experiments

1. Rollback-set prediction: classify must_rollback per component (F1); compare full rollback (all changed components) and 'roll back only symptomatic components' baselines.
2. Graph learning: GNN or graph-feature model using the edges table vs tabular model; report F1 and set-level exact match per deployment.
3. Root-cause localisation: rank components by predicted root_cause (top-1/top-3 accuracy per deployment).
4. Cost of rollback: number of components rolled back unnecessarily vs dependency violations left (consumers kept on a contract whose provider was rolled back).
